## 一、下载与登录

1. 打开 [KOOK 官网](https://www.kookapp.cn/)，选择适合设备的官方客户端。
2. 按页面提示安装并打开软件，或使用官网提供的网页版入口。
3. 按当前页面要求注册账号；已有账号的用户可直接登录。
4. 首次使用语音时，根据系统提示允许 KOOK 使用麦克风。

电脑上长时间游戏语音建议优先使用桌面客户端；网页版可能受到浏览器权限、后台休眠等因素影响。不同平台的功能和按钮位置可能不同，以当前官方页面为准。

**不要从不明网盘、广告页面或陌生人提供的安装包下载软件，也不要向他人提供验证码或密码。**

## 二、加入社团 KOOK 服务器

KOOK 中的“服务器”是包含文字频道和语音频道的交流空间，**并不是 Minecraft 游戏服务器**。加入 KOOK 不等于已经加入游戏。

1. 从社团公告或管理员处获取 KOOK 邀请链接。
2. 打开链接，检查显示的服务器名称是否正确。
3. 按提示登录并加入；如果需要在客户端打开，确认启动的是官方 KOOK 客户端。
4. 阅读欢迎频道、公告及使用规则。
5. 如果服务器要求验证或领取身份组，按照公告完成操作。

**社团邀请链接：请通过社团公告或 QQ 群获取。** 社团 QQ 群为 **763729280**。

如果加入后看不到活动频道，可能是身份组或频道权限尚未开通，请联系管理员，不要重复创建账号。

## 三、设置昵称与通知

为了方便认人，可以按照社团规则设置昵称，例如使用大家熟悉的称呼或游戏 ID。若当前版本支持服务器内昵称，可优先只修改社团服务器中的昵称。

建议根据需要调整消息通知：保留活动通知，减少不必要的频道提醒；不要将所有重要通知全部关闭后错过活动安排。

不要在公开昵称、个人资料或截图中暴露学号、手机号等不必要的个人信息。

## 四、进入语音频道

1. 在社团 KOOK 服务器的频道列表中，找到活动指定的语音频道。
2. 点击或按客户端提示加入频道。
3. 确认界面显示你已经连接语音，再与其他成员交流。
4. 暂时离开时可以静音，结束使用后点击断开或离开语音。

| 控制项 | 常见作用 | 使用提示 |
| --- | --- | --- |
| 麦克风静音 | 停止将你的声音发送给其他人 | 暂离、咳嗽或环境嘈杂时使用 |
| 耳机/停听 | 停止收听频道声音 | 部分客户端也会同时关闭发言，留意界面状态 |
| 断开语音 | 离开当前语音连接 | 不要只切换文字频道就以为已经离开语音 |

没有发言时建议保持安静，避免外放音乐、长时间杂音和抢话。加入多人活动频道后，先听清组织者的安排。

## 五、调好麦克风与耳机

在用户设置中寻找“语音”“音频”或类似页面，菜单名称以当前客户端为准。

### 选择正确的设备

- **输入设备**：选择实际使用的麦克风，例如耳机麦克风或 USB 麦克风。
- **输出设备**：选择实际使用的耳机或扬声器。
- 如果使用“系统默认”，切换蓝牙耳机、显示器或声卡后，需要重新检查设备是否变化。

建议佩戴耳机，避免扬声器声音被麦克风再次收录，造成回声。

### 选择发言方式

如果当前客户端提供相关选项，可按环境选择：

- **语音激活**：讲话时自动发送声音，适合环境安静的情况。
- **按键说话**：按住指定按键才发送声音，适合宿舍、公共空间或活动指挥。

按键说话的快捷键尽量避开 Minecraft 的移动、背包、聊天等常用按键。设置后请在游戏窗口处于前台时实际测试，不要只在设置页面测试。

### 测试音量

1. 使用客户端提供的麦克风测试功能（如有），或请同伴协助试音。
2. 正常音量说一句话，检查是否能够完整听清。
3. 根据反馈调整输入音量、灵敏度或降噪选项。
4. 声音太小、断断续续或严重失真时，先检查设备和增益，不要直接把所有音量拉满。

## 常见问题

### 我能听到别人，但别人听不到我

依次检查：

1. 是否关闭了麦克风，或被频道管理者限制发言。
2. 如果启用了按键说话，是否按住正确按键。
3. 输入设备是否选成了未连接的麦克风或虚拟设备。
4. 操作系统是否允许 KOOK 或浏览器使用麦克风。
5. 浏览器是否拒绝了该站点的麦克风权限。
6. 语音激活阈值是否过高，导致正常说话无法触发。

可以先使用系统录音功能测试硬件；如果录音也没有声音，优先处理系统或设备问题。

### 看得到频道，但听不到其他人

确认已经加入语音，而不是仅打开了文字聊天；然后检查停听状态、输出设备、系统混音器音量，以及是否将某个成员单独静音。

### 声音有回声或杂音

优先佩戴耳机，确认同一房间没有多台设备同时外放并开麦。适当开启降噪或回声消除（如有），嘈杂环境可改为按键说话。

### 切换到 Minecraft 后按键说话失效

检查快捷键是否冲突，客户端是否仍在运行，以及系统是否限制全局快捷键。部分情况下程序权限级别不同会影响按键捕获，应优先避免不必要的管理员运行，不要直接关闭安全防护。

### 邀请链接打不开或提示失效

检查是否复制完整、是否已登录，以及链接是否过期或服务器是否限制加入。请通过社团公告重新获取，不要尝试来历不明的“替代邀请”。

### 游戏流畅，但语音卡顿

检查网络与后台下载，暂时停止整合包更新、直播或大文件传输；也可尝试重新连接语音。若多人同时遇到问题，向管理员反馈发生时间与提示信息。
