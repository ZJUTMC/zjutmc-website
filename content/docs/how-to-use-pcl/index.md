PCL（Plain Craft Launcher，常称 PCL2）是一款用于管理和启动 Minecraft Java 版的第三方启动器。本文以 Windows 上常见的 PCL 使用流程为例，具体按钮名称以实际版本为准。

**项目入口：[PCL2 官方项目仓库](https://github.com/Hex-Dragon/PCL2)**，请从项目说明指向的正式渠道获取启动器。

> **已经会用其他启动器？** 先确认游戏目录与版本隔离，导入社团指定整合包或安装所需版本，再配置对应账号、Java 与内存。不要把“装了启动器”误认为已经拥有游戏授权或已经满足服务器要求。

## 一、准备启动器

1. 从正式渠道下载适用于设备的 PCL 版本，阅读对应版本的使用说明。
2. 如果下载的是压缩包，先完整解压，不要直接在压缩包内运行。
3. 将启动器放在便于管理、有写入权限且磁盘空间充足的独立目录，例如 `D:\Games\Minecraft\PCL\`。
4. 打开启动器，按照提示完成必要的运行环境准备。

PCL 主要面向 Windows 使用场景，不是基岩版启动器；其他系统应选用明确支持该系统的工具。不要把“PCL 手机版”等不明程序视为同一项目。

**不要随意关闭安全软件或运行来源不明的安装包。** 出现安全提示时，先核对下载来源、发布说明及文件信息。

## 二、确认游戏目录与版本隔离

启动器程序、游戏文件和单个版本的存档、配置不一定在同一个文件夹，开始前先确认实际游戏目录。

建议启用适合自己需求的**版本隔离**，使不同游戏版本或整合包各自使用独立的模组、配置与存档，减少互相干扰。具体隔离规则以启动器当前说明为准。

- 新建整合包时，优先使用独立版本或独立游戏目录。
- 放入模组、资源包、光影前，先从当前版本的“打开文件夹”或类似入口确认目标目录。
- 更改隔离设置前，先备份原有存档和配置，避免误以为文件消失后覆盖旧数据。

**升级、迁移或删除版本前，请备份重要存档。** 不要对唯一一份存档直接进行跨大版本或跨整合包测试。

## 三、选择正确的账号方式

不同服务器允许的登录方式不同，按照服务器公告选择，不要把网页登录、启动器登录和进入服务器的验证混为一谈。

### 微软账号登录

如果使用正版 Java 版账号，选择启动器提供的微软登录入口，按照官方授权流程完成登录并选择角色。

- 确认账号具有相应 Java 版游玩权益。
- 在微软官方授权页面完成验证，不要将密码或一次性登录代码发送给他人。
- 已成功登录但提示无游戏资格时，检查是否选错微软账号或授权状态异常。

### 社团指定的外置登录

如果服务器明确要求皮肤站外置登录，按管理员说明添加实际认证服务器，再使用该皮肤站的账号和角色启动游戏。

**不要自行把皮肤站首页地址当成认证接口。** 社团皮肤站的账号准备与皮肤设置可参考[皮肤站使用指南](/docs/how-to-use-skin-zjutmc-top/)，但是否支持外置认证及其配置仍以管理员通知为准。

### 离线模式

仅在服务器明确允许且符合相关规则时使用。离线模式不代表拥有游戏授权，也不能用于绕过要求正版认证的服务器。

**不要随意切换账号类型、角色名或身份。** 服务器可能把它们识别为不同玩家，从而影响白名单、背包与存档归属。

## 四、安装游戏或导入整合包

### 方法 A：使用社团提供的整合包

如果社团已经提供对应服务器的整合包，优先使用该整合包，不要自行拼装不同版本的模组。

1. 从社团公告或管理员提供的可信渠道下载整合包，并核对名称和版本。
2. 在 PCL 中寻找整合包导入入口，或将支持的整合包文件拖入启动器窗口。
3. 按提示确认安装名称、目录等选项，等待下载与安装完成。
4. 阅读整合包附带的 Java、内存、登录方式及服务器说明。
5. 在启动页选择刚安装的版本，确认没有选错另一个整合包。

不是所有 `.zip` 文件都是启动器支持的整合包格式。如果导入失败，请先确认它是标准导出包、完整客户端压缩包，还是普通备份；不要直接把压缩文件放入 `mods` 文件夹。

如果管理员提供的是完整客户端，请按附带说明解压与启动，并确认其中是否已经包含启动器及配置，不要直接覆盖现有游戏目录。

### 方法 B：手动安装版本

1. 在下载或版本安装页面选择服务器要求的 **Minecraft 精确版本**。
2. 如果服务器或整合包需要 Forge、Fabric、NeoForge 等加载器，选择匹配的类型与版本。
3. 为安装项设置便于区分的名称，然后等待完成。
4. 需要额外模组时，只安装可信来源、与当前版本及加载器匹配的文件。

不同加载器的模组通常不能混用；例如为 Forge 制作的模组不能默认放进 Fabric 环境。纯原版客户端也不能自动运行模组服要求的所有功能。

## 五、检查 Java 与内存

### Java 版本

Minecraft 不同版本对 Java 的要求不同，整合包与加载器还可能有额外限制。以下仅为常见参考，不代替整合包说明：

| 游戏版本范围 | 常见 Java 要求或选择 |
| --- | --- |
| 1.16.5 及更早的常见旧整合包 | 通常使用 Java 8，仍需核对具体包的要求 |
| 1.17.x | 通常使用 Java 16 |
| 1.18 至 1.20.4 | 通常使用 Java 17 |
| 1.20.5、1.20.6 及 1.21.x | 通常使用 Java 21 |
| 其他或更新版本 | 查阅对应游戏、加载器与整合包说明 |

如果启动器提供自动选择或下载 Java 的功能，可以先使用，但出现错误时仍需检查实际选中的 Java 路径与版本。不要认为 Java 越新越适合旧整合包。

### 内存分配

优先按照整合包推荐值设置，使用自动配置时也要留意系统剩余内存。

- 轻量原版通常不需要分配特别大的堆内存。
- 大型模组包往往需要更多内存，具体以包的说明为准。
- 给操作系统、浏览器、KOOK 及其他程序保留足够空间。
- 不要把电脑全部物理内存都分配给 Minecraft，也不要把提高内存当成所有卡顿问题的解决方案。

## 六、启动并加入服务器

1. 在启动页确认所选游戏版本、账号和角色正确。
2. 点击启动，等待游戏窗口打开；首次启动可能需要下载资源，避免重复点击启动多个实例。
3. 进入标题界面后，打开“多人游戏”。
4. 点击“添加服务器”，填写社团公布的服务器地址。
5. 保存并连接，按服务器公告完成白名单或其他必要验证。

**服务器地址：请通过社团公告或管理员获取。** 不要把社团网站、皮肤站或 KOOK 服务器名称直接当作 Minecraft 服务器地址。

收到“缺少模组”“模组版本不一致”或“版本不匹配”时，优先检查整合包与客户端版本；不要靠随机删除模组来尝试连接。

需要游戏语音时，可参考 [KOOK 语音软件使用指南](/docs/how-to-use-kook/)。

## 七、模组与文件放在哪里

从 PCL 中打开**当前版本实际使用的游戏文件夹**，再寻找以下目录；具体路径会受游戏目录与版本隔离设置影响。

| 目录 | 常见用途 | 注意事项 |
| --- | --- | --- |
| `mods` | 模组文件 | 需要对应加载器、游戏版本及前置依赖 |
| `resourcepacks` | 资源包 | 复制后通常还要在游戏设置中启用 |
| `shaderpacks` | 光影包 | 需要兼容的光影支持与硬件环境 |
| `saves` | 单人存档 | 覆盖、迁移或跨版本打开前先备份 |
| `screenshots` | 游戏截图 | 发布前检查画面中的聊天及隐私信息 |
| `logs` / `crash-reports` | 运行日志与崩溃报告 | 求助时有用，分享前检查敏感内容 |

不要把所有下载文件都放进 `mods`，也不要在不了解作用时删除配置、日志以外的数据。社团整合包更新应遵循对应的更新说明。

## 常见问题

### 启动器打不开

核对系统支持范围、下载完整性及对应版本需要的运行环境。查看正式项目说明，避免盲目安装来源不明的“修复工具”。

### 下载很慢或失败

先检查网络连接、磁盘空间以及启动器提供的下载设置；必要时稍后重试。不要随意使用不可信代理或陌生人提供的替代文件，也不要将账号令牌交给所谓加速服务。

### 提示 Java 不兼容或直接闪退

检查当前版本实际使用的 Java；再核对加载器、模组及依赖版本。优先查看第一条有用的错误信息，不要只反复增加内存。

### 提示模组缺少依赖或版本不匹配

确认整合包版本、加载器及模组来源一致。优先重新获取社团指定版本，并保留存档备份；不要把另一整合包的整个 `mods` 目录直接覆盖进来。

### 微软登录或外置登录失败

核对所选登录方式、账号、网络与系统时间；外置登录还要确认认证服务地址正确且服务器支持该方案。不要将完整登录日志直接公开，其中可能包含敏感信息。

### 能进入游戏，但进不了服务器

记录完整提示，分别检查游戏版本、模组列表、服务器地址、服务器维护状态、白名单与账号认证。游戏能启动不代表满足服务器的连接条件。

### 游戏很卡，是否应该增加内存

先判断是帧数低、加载卡顿还是网络延迟。降低渲染距离、关闭过重的光影或后台程序可能更有效；仅在内存确实不足且系统有余量时调整分配。

## 求助前准备

向管理员反馈时，尽量一次提供以下信息：

- 问题发生在下载、登录、启动还是连接服务器阶段。
- PCL 版本、Minecraft 版本、加载器与整合包版本。
- 实际使用的 Java 版本、内存分配及完整错误提示。
- 必要时附上日志或崩溃报告，先遮挡账号、令牌和其他隐私信息。
