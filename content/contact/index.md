## 合作与咨询

想与浙江工业大学MC方块社一起策划活动、开展社团联动，或交流 Minecraft 创作与校园项目？欢迎联系我们，一起把想法搭建成现实。
有关加入社团、参与活动等问题，也可以通过以下方式咨询。

- **合作咨询与社团联系邮箱**：`zjutmc@163.com`

联系时请简要说明你的称呼、所在组织（如有）与来意；合作邀约可附上项目介绍、预计时间和希望的合作方式，方便我们进一步沟通。

## 问题与建议反馈

无论是游戏中遇到的问题，还是对社团建设的想法，都欢迎告诉我们。请根据反馈内容填写对应方向，方便相关负责人跟进。

- **问题与建议反馈邮箱**：`zjutmc@163.com`

| 反馈方向 | 可以反馈的内容 |
| --- | --- |
| 纯原服务器反馈 | 连接异常、卡顿、游戏机制异常、违规行为与游玩体验建议 |
| GTNH服务器反馈 | 整合包安装与连接问题、任务或配方异常、服务器故障及私货建议 |
| 长短期模组、整合包服务器反馈 | 整合包安装与连接问题、服务器故障及玩法建议 |
| 社团管理与制度建议反馈 | 社团章程、成员权益、管理流程及规则完善建议 |
| 社团网站问题与建议反馈 | 页面错误、失效链接、教程修订、功能与无障碍体验建议 | 提交 [GitHub Issues](https://github.com/ZJUTMC/zjutmc-website/issues) |

*仅社团官网 www.zjutmc.top 问题可以提交到 Github Issues ，社团皮肤站运营问题请提交到社团邮箱。
为了更快定位问题，建议在反馈中附上：**问题描述、发生时间、涉及的服务器或页面、复现步骤，以及必要的截图或报错信息**。提出建议时，欢迎说明现有困扰和你期望的改进方式。

请勿在公开反馈中上传密码、令牌、个人隐私或未经脱敏的日志。涉及成员隐私、违规举报等内容，请通过对应的私下联系方式提交。
