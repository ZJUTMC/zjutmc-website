我们是 **浙工大 MC 方块社（ZJUTMC）**，全称浙江工业大学 MC 方块社。社团成立于 **2022 年**，是一群热爱 Minecraft（我的世界）的工大学生相聚的学术科技类学生社团。

我们以 Minecraft 为载体，把联机游戏、建筑创作和技术实践带进课余生活。你可以和伙伴一起探索生存世界、挑战趣味地图，也可以参与校园复刻，或从运行一台游戏服务器开始，接触新的计算机知识。

> 用方块创造价值，用游戏体验现实。

这是写在社团章程中的宗旨，也是我们开展活动的出发点：让兴趣有发挥的空间，让想法有动手实现的机会，让原本陌生的同学通过共同的爱好认识彼此。

## 我们一起做什么

### 联机探索和趣味挑战

从原版生存、合作建设，到 Bingo、冰船竞速、跑酷等小游戏，社团活动覆盖不同的玩法和参与节奏。你可以慢慢搭建自己的小屋，也可以和伙伴尝试新的地图，在一次次配合与挑战中熟悉彼此。

除了日常的周常小游戏，我们也组织过[“方块竞速”比赛](/activities/block-race/)，与校内外的 Minecraft 爱好者交流。活动的乐趣既在于完成挑战，也在于一起讨论路线、分享技巧，留下属于大家的游戏瞬间。

### 用方块记录工大

[“方块工大”校园复刻项目](/activities/campus/)把我们熟悉的校园带进 Minecraft。从实地观察、拍照收集，到讨论建筑比例、选择方块材质和协作搭建，参与者在认识校园的过程中，尝试用自己的方式还原校园。

社团曾在校内市集中展示屏峰校区板球馆的复刻成果，也开展过朝晖校区的线下勘测。校园复刻并不只是照着照片搭建筑：它需要观察、沟通和耐心，也让我们重新留意每天经过的那些地方。

### 从游戏兴趣走向技术实践

Minecraft 也是学习技术的入口。社团曾与校内 Linux User Group（LUG）合作开展[“Linux 上的 MC 服务器”系列课程](/activities/linux-workshop/)，通过讲解和实操，带同学接触 Linux、Java 环境、服务端配置、插件与服务器管理。

我们的学习实践方向也包括建筑设计、红石机械、自动化逻辑，以及 Java 和模组开发。无论是研究一个红石装置，还是尝试搭起自己的服务器，都可以从一个具体问题开始，在交流和实践中逐步深入。

### 在校园里见面

方块社的交流也在线下发生。百团大战、社团文化周和校园市集，都是我们展示作品、介绍玩法、认识新朋友的机会。我们还开展过“教你从 0 装 MC”线下活动，帮助同学处理游戏安装、Java 环境和启动配置等入门问题。

线上一起游玩的伙伴，也可以在线下聊聊作品、交流技术，让共同的兴趣延伸到校园生活中。

## 刚接触 Minecraft 也欢迎

你不必先成为建筑高手、红石玩家或开服专家，再来认识方块社。第一次进入游戏、想试试联机，或只是对方块创作有一点好奇，都可以从了解活动和阅读入门文档开始。

我们希望让不同经验的同学都能找到参与的方式。新玩家可以从简单的玩法和基础操作入手，熟悉游戏的同学可以分享经验，也可以在新的地图、项目和技术问题里继续探索。

## 我们珍惜怎样的相处

友善交流、尊重彼此，是一起游戏和创作的基础。讨论玩法时愿意听取不同意见，协作搭建时认真沟通，遇到问题时互相帮助，比一次比赛的名次更能让这个社群长久地走下去。

社团成员应遵守学校相关规定、社团章程和社区规范，共同维护良好的交流与活动环境。我们也欢迎成员对活动安排、社团管理和社区建设提出建议。

## 如何参与

按照社团章程，正式社团成员面向具有正式学籍的浙江工业大学在读学生。希望加入的同学，可以关注校园招新和社团活动通知，具体入社流程以当期招新通知为准。

- [社团活动](/activities/)：了解我们的活动与项目。
- [帮助文档](https://docs.zjutmc.top/)：查阅入门和使用帮助。
- [社团皮肤站](https://skin.zjutmc.top/)：访问社团皮肤服务。

欢迎来到浙工大 MC 方块社。从一次联机、一场活动或一块方块开始，和我们一起创造属于自己的故事。
